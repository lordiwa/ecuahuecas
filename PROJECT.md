# ecuahuecas

## Description
Sitio editorial de reseñas de comida de calle ecuatoriana (huecas), escrito por un colectivo curado de críticos

## Target users
Lectores ecuatorianos que buscan huecas reales (carretillas, mercados, picanterías de barrio) y el colectivo curado de críticos que escribe las reseñas

## Primary use cases
- data-entry, collaboration

## Success criteria
Los lectores descubren huecas reales mediante reseñas honestas en jerga ecuatoriana; sitio SSG con SEO y previews sociales, mobile-first y costo acotado a free tiers de Firebase

## Stack
- frontend_framework: vue
- backend_framework: firebase
- database: firestore
- web_deployment_target: firebase-hosting
